## Candidate policy

The exact Community Laptop policy version 0.1.0-candidate.3 targets
supported Windows 11 native x64 laptops. The rules require sanitization,
platform and ownership evidence, activation, firmware and security
checks, and applicable manual functions. The candidate thresholds are
8 GiB installed memory, 128 GiB system capacity, 32 GiB free system
space and a 60 percent battery full-charge ratio. These are recorded
pilot policy choices. Windows Update, finalization and independent
handover verification retain their separate evidence paths.
