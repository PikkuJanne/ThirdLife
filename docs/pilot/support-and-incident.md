# Controlled pilot support and incidents

The reviewed job remains the workshop record. For a suspected bad package,
catalogue mismatch, unexpected privileged operation, data exposure or
failed independent check, stop the affected action. Keep the current job
and the reviewed package identity. If an operation was interrupted, open
the same job and retain its unresolved result. [Security reporting](../../SECURITY.md)

Use Handover's sanitized support preview to review the exact archive before
saving a copy to an explicitly chosen protected local folder. The saved
receipt is bound to that preview. If publication was interrupted, select
the original protected folder during recovery. The tool checks the
existing bytes against the saved digest.

Recipients and operators control forwarding of a saved copy through the
authorized support route. Keep full workshop reports, identifiers,
credentials, recovery material and personal files in their existing
custody. A partner-specific contact and permitted transfer route belong
in the TL-0611 exposure record. [Privacy and export limits](../privacy/privacy-model.md)
