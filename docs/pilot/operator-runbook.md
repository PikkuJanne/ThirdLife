# Controlled pilot operator runbook

This draft describes the current private TRACE workflow. TL-0611 holds
partner exposure. The active app runs unelevated and preserves the workshop
job between stages. [Deployment](deployment-rollback.md)

1. In **Intake**, create or reopen the correct job and record the evidence
   from the approved external sanitization route. Stop preparation if the
   required sanitization or ownership checkpoint is missing.
2. In **Inspect**, run the inventory and complete the applicable manual
   checks. Review unknown, degraded or unobserved results before choosing
   a disposition. Retain their limitations in the job.
3. Review the applicable policy and reasons. In **Prepare**, review the
   exact plan, provider, actions and prerequisites. Approve only the
   intended action and scope. Windows consent applies to the exact approved
   action where required. A missing provider or held action stays pending.
4. If preparation stops or Windows restarts, reopen the same job in
   **Verify**. Read the saved result and use its matching recovery or
   independent verification route. An interrupted action requires its own
   evidence before any retry or completion claim.
5. In **Handover**, record the assisted or sealed choice with the operator
   attribution. Review the blocking checklist, check for workshop residue
   and preview the current workshop report and recipient guide. Save the
   versions bound to the current job. Keep the restricted workshop report
   under workshop custody. Sealed handover leaves personal setup pending.
6. Record sign-off only when the current job passes its required checks.
   Record the support archive outcome or attributed omission. An open
   obligation remains visible in the saved job.

For a disputed target, suspected compromise, unexpected elevation or an
unsupported action, stop the affected preparation. Preserve the job and
existing evidence. Follow the incident route before retrying an action in
the affected scope. [Support and incidents](support-and-incident.md)
