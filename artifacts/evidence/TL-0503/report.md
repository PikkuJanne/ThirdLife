# TL-0503 — Preparation resource preflight

## Application outcome

Prepare checks the current Windows 11 client and native x64 identity, local storage, and power before requesting the reviewed installer for the plan. The application repeats the check before an approved attempt acquires the installer and after staging, before calling Windows Installer. The exact saved plan, approval, sanitization decision and dispatch intent are revalidated after the last resource read.

A resource refusal before intent leaves any saved approval and prior attempt intact. With a current exact approval the operator can request installation again after restoring resources. A refusal after staging records a correlated resource deferral at the pre-dispatch failure checkpoint. Verify and the restricted workshop report show that Windows Installer did not start. Reopening the job preserves the outcome and offers the existing bounded retry route when eligible. The native read does not become an approval or an independent installed-state result.

Prepare and Verify show the current check time, available bytes and requirements where available, and an actionable explanation. The updated WPF status is keyboard focusable and uses a polite live region. The current observation stays in memory. Only the existing restricted journal and report surfaces receive the new bounded late-deferral outcome. Drive letters, paths, volume identities, raw power fields and exact capacity observations are excluded from persisted evidence. Prior job and approval values keep their original meaning. Earlier binaries predate the added outcome value.

## Policy and scope

- Windows storage reserves 1 GiB after preparation, 128 MiB for installer overhead and rollback, and the installation estimate. Download storage reserves 128 MiB plus the declared download. The shared-volume case adds both requirements and uses the lower caller-available reading. The final check accounts for the exact installer already staged when calculating remaining space. The backend retains its independent staging and trust checks.
- The pinned Notepad++ 8.9.9.1 MSI has a reviewed download size of 7,933,952 bytes. Its catalog still reports installed size as unknown. The file payload review supports a 28,130,419-byte base allowance for that exact installer digest, with separate overhead. The shared-volume requirement before download is 1,378,241,651 bytes. Prepare labels the installed size uncertain. Missing estimates without applicable reviewed evidence defer work. [Exact package review](../../../docs/adr/0009-winget-backend.md)
- The route observes Windows, native Program Files and Local Application Data on fixed local storage. If Program Files cannot be confirmed on the Windows volume, the required system capacity remains unavailable. The storage check uses bytes available to the current caller, including quota limits. Reparse and nonlocal staging paths do not provide qualifying evidence. [Windows disk capacity API](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getdiskfreespaceexw) [Windows volume identity API](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getvolumenameforvolumemountpointw)
- A computer with a system battery needs observed external power and at least 10% charge. A native critical flag, unavailable or contradictory power evidence, or battery-only operation defers package work. A coherent no-battery report permits the power check. These are pilot engineering defaults for the reviewed route. The Windows power result is a point-in-time observation. [Windows power status fields](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-system_power_status)

The package action preflight works within the existing reviewed package route. Synthetic broker no-ops have no package storage or power requirement. An observation remains a snapshot. Later changes during a native installer transaction, live loss of power, unusual known-folder changes during staging, physical storage exhaustion and other device configurations remain outside this evidence.
