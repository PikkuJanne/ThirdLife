## Accessibility defect and runner record

The stage-transition focus issue was fixed and the original keyboard
cases passed on their recorded source. The backup review now clears
obsolete consent and scope when inputs or job context change.
[Stage focus regression](../evidence/TL-0608/stage-focus.md)

The external wheel runner first expired on the empty Jobs surface.
The next method waited for real vertical overflow in populated Intake.
A separate attempt routed the UI Automation bounds, pointer and window
hit test through physical screen coordinates. That run still observed
no scroll progress after the first detent. The pointer was restored and
the owned fixture exited normally. The later test fixture recorded one native wheel message and zero
routed WPF wheel events during the failure. The runner now positions
the pointer over the owned shell, sends a small mouse move and
verifies a routed pointer event before injecting the first wheel input.
The clean Release run at `e1281fbe7e4acd428fd1d861b8326a2dd88ab71e` took 14.438 s.
All seven native wheel messages reached WPF. Six fractional pulses
increased the visible vertical scroll position at every step and
reached the same 10.743% offset as the full detent. The same run passed
all three UI Automation announcements and reopened the saved intake,
assessment, manual result and workshop report.
[WPF mouse input source](https://source.dot.net/presentationcore/System/Windows/InterOp/HwndMouseInputProvider.cs.html)
[Microsoft UI Automation coordinate guidance](https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-screenscaling)

The existing full external command continues to include wheel checks.
The independently selectable `-VerifyAccessibility -KeyboardOnly`
mode completed in 12.144 s on the same clean source. Its result
explicitly records that wheel input was outside that run.
Targeted verification passed 1,448 Quick tests and the five focused
wheel regression cases in 200.499 s.
Audible perception and the wider assistive-technology matrix remain
open at the pilot and release decisions.
